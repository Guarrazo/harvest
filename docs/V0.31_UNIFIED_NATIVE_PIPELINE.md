# NCIG v0.31 — Unified native test pipeline

## What changed

- Fixed lateral exterior-entry collision headers for west/east entrances.
- Fixed the v0.28 stairwell collision problem: floor collisions are now segmented around the vertical shaft on non-top floors of multi-storey continuous cores.
- Added a single native-test launcher that reuses the already completed detector, structural layout and architecture assembly outputs.

## User-facing workflow

Once one real World Builder/Object Spawner export containing at least one static-mesh worldMeshNode exists, the complete native test pipeline is one command:

~~~cmd
.\tools\continue_native_pipeline_cp2077.cmd "C:\path\to\real_mesh_export.json"
~~~

The default first target is auto_10712_industrial, but a second argument can select another generated building.

This launcher does not rerun city detection, candidate refinement, procedural generation or v0.28 structural generation. It extracts/merges the real node templates, composes one building, generates structural collision and runs the native integrity audit automatically.

The final external validation is WolvenKit import followed by an in-game test.
