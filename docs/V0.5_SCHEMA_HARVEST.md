# NCIG v0.5 — public schema + automatic harvest

The manual “probe pack” is no longer the primary workflow.

NCIG v0.5 adds two layers:

1. **Reference serializers** for node payloads documented by World Builder / entSpawner.
2. **Automatic harvesting** of real World Builder/Object Spawner JSON and mod data, so runtime-sensitive templates can be recovered from existing files instead of manually rebuilt in World Builder.

## Commands

```powershell
$env:PYTHONPATH="$PWD/src"
python -m ncig.cli schema-report --out build/schema_report.json
```

Harvest World Builder / entSpawner and installed mod data:

```powershell
python -m ncig.cli harvest `
  --root "C:\Cyberpunk 2077\bin\x64\plugins\entSpawner" `
  --out build/harvest.json `
  --templates-out build/templates.json
```

Then bridge a generated NCIG plan without a manual probe group:

```powershell
python -m ncig.cli schema-bridge `
  --plan build/generated/wb_plans/demo_shop_001_world_plan_v2.json `
  --base examples/ncig_probe_exported.json `
  --assets build/harvest.json `
  --templates build/templates.json `
  --out build/demo_shop_001_schema_object_spawner.json
```

`--base` is optional. When supplied it provides the exact World Builder envelope (version, sector fields, etc.); it is not used as a mandatory node-type probe.

## What is harvested

The harvester looks through JSON/Lua/text files for:

- real Object Spawner node payloads (`worldEntityNode`, `worldMeshNode`, `worldStaticLightNode`, `worldCollisionNode`, etc.);
- `DepotPath` / `spawnData` / mesh/entity resource paths;
- resource-role hints such as floor, wall, ceiling, bed, office, bathroom, etc.

This lets existing World Builder favorites/prefabs and mods act as a **local template library**.

## Safety rule

NCIG only synthesizes a node directly when the exporter schema is sufficiently known. Enum-heavy fields (for example some mesh/light options) prefer a harvested real template. If no safe resource/template is available, NCIG skips the node and records the reason instead of producing a plausible-looking but unverified payload.
